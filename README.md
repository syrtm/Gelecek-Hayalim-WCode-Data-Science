# Gelecek Hayalim WCode Data Science

This project was developed as part of the Gelecek Hayalim WCode Data Science program. It focuses on applying data science techniques to analyze and model various datasets.

## Project Overview
The final project aims to explore the impact of gender inequality on mental health using data science methodologies. The main objectives include:
- **Data Collection & Preprocessing:** Gathering and cleaning relevant datasets.
- **Exploratory Data Analysis (EDA):** Visualizing and understanding data patterns.
- **Machine Learning Applications:** Implementing predictive models to assess trends and correlations.
- **Model Evaluation & Insights:** Analyzing model results and drawing conclusions.
